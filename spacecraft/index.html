Corp sync (Supabase)

Free shared database so all 4 of you see the same data. One of you creates the project, everyone pastes the same values here.

One-time setup (project owner)
  1. Create a free project at supabase.com
  2. SQL Editor → run:
    create table corp_state (room text primary key, data jsonb, updated_at timestamptz default now());
    alter table corp_state enable row level security;
    create policy "open" on corp_state for all using (true) with check (true);
  3. Project Settings → API → copy URL + anon key, share with the corp along with a room code.

Backup / share without sync

Export your corp data as a file and share it on Discord; others import it.
